# Requirements

The same across every plugin in the suite.

| | |
|---|---|
| **Operating system** | macOS 13 (Ventura) or later |
| **Hardware** | Apple Silicon Mac (M1 / M2 / M3 / M4) |
| **TouchDesigner** | 2025 or later |

These plugins are built directly on Apple's Vision framework, so a few boundaries follow from that:

- **macOS and Apple Silicon only** — there's no Windows or Intel build.
- **No custom models** — you get what Vision provides, not a runtime for your own networks.
- **Nothing else to install** — no Python environment, no model files, no network or account. Detection runs on-device and works offline.
